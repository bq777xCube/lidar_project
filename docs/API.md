# Вход, выходы и состояния ROS 2

[К началу](../README.md)

## Вход

Топик по умолчанию: `/lidar_points`. Тип: `sensor_msgs/msg/PointCloud2`.

Обязательны три поля `x`, `y`, `z`: по одному значению **FLOAT32, datatype=7, count=1**. FLOAT64 для XYZ текущий адаптер отклоняет. Порядок полей произвольный, смещения не должны пересекаться. Размер данных должен совпадать с `row_step × height`.

Поддержаны предоставленные схемы 16 и 26 байт на точку, другие корректные смещения, оба порядка байтов и организованные облака с заполнением строк. Дополнительные поля игнорируются. Их наличие не выбирает алгоритм и не заменяет проверку XYZ.

`header.stamp` задаёт последовательность для S2. Частота выхода определяется реально обработанными сообщениями, а не независимым таймером 10 Гц.

## Выходы

| Топик | ROS-тип | Значение |
|---|---|---|
| `/foreign_object/obstacle` | `std_msgs/msg/Bool` | Подтверждено ли препятствие в текущем результате |
| `/foreign_object/distance` | `std_msgs/msg/Float32` | Расстояние в метрах; `-1.0` при отсутствии подтверждённого расстояния |
| `/foreign_object/state` | `std_msgs/msg/String` | Состояние решения |
| `/foreign_object/horizon` | `std_msgs/msg/Float32` | Измеренный поддержанный горизонт пути, м; `-1` при ошибке входа |
| `/foreign_object/processing_ms` | `std_msgs/msg/Float32` | Время callback до публикации, включая разбор входа и вычисления; не полная задержка доставки |
| `/foreign_object/track_quality` | `std_msgs/msg/String` | Качество геометрии: `GOOD`, `DEGRADED` или `INVALID` |
| `/foreign_object/source` | `std_msgs/msg/String` | Выбранный источник; пустая строка при отсутствии источника допустима |

## Состояния и источники

| Код | Смысл |
|---|---|
| `CLEAR` | Подтверждение препятствия в доступной области отсутствует |
| `TRACK_UNRELIABLE` | Рельсовая опора ненадёжна; это не утверждение о свободном пути |
| `OBSTACLE_NORMAL` | Положительный результат основного или дополнительного точечного канала |
| `OBSTACLE_SPARSE` | Подтверждение исходного разреженного канала S2 |
| `NEAR_NORMAL`, `NEAR_SPARSE` | Измеренная ближняя геометрия; расстояние по оценке дуги |
| `SYNTHETIC_MEASURED` | Дополнительное текущее свидетельство внутри измеренной геометрии; расстояние по дуге |
| `SYNTHETIC_NOMINAL_BRIDGE`, `FAR_SYNTHETIC_BEAM` | Переходная или дальняя синтетическая ветвь; продольная координата N1 |

Полный набор служебных кодов: [Справочник строк](CONTRACT_STRINGS.md). Идентификаторы не переводятся, чтобы сохранить совместимость.

## Свежесть и ошибки

Семь отдельных сообщений не имеют общей временной метки. Они **не являются атомарным пакетом**. Потребитель контролирует свежесть выходов и не принимает сохранённые значения после остановки входа за новое решение. Остановка плеера не публикует автоматически `CLEAR`.

`watch_outputs.py` наблюдает три основных выхода и при отсутствии свежих сообщений сообщает `UNKNOWN`, завершаясь с кодом 2. Это внешний наблюдатель, не таймер внутри детектора.

Повреждённый вход отклоняется, состояние S2 сбрасывается, публикуются `false`, `-1`, `TRACK_UNRELIABLE` и качество `INVALID`. Ошибочный топик не создаёт свежих результатов. Возврат времени назад и крупный разрыв отражаются в логах как `TIMESTAMP_ROLLBACK` и `TIMESTAMP_GAP`/`FRAME_GAP`.

## Параметры узла

`config` задаёт путь к файлу конфигурации, `input_topic` переопределяет входной топик, `debug` включает подробный аудит. Изменение этих параметров пересоздаёт детектор и сбрасывает историю S2.

Входная подписка: best-effort, volatile, depth=1. Совместимость публикатора и сеть должны обеспечивать доставку PointCloud2. Параметры запуска и пример наблюдателя: [Развёртывание](DEPLOYMENT.md).
