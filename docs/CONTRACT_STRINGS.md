# Машинные коды и причины сброса

| Код | Русский смысл |
|---|---|
| CLEAR | Подтвержденного препятствия в доступной области нет |
| TRACK_UNRELIABLE | Геометрия пути ненадежна; не считать свободным путем |
| OBSTACLE_NORMAL | Подтверждение основной или синтетической ветви |
| OBSTACLE_SPARSE | Разреженное подтверждение S2 |
| NEAR_NORMAL / NEAR_SPARSE | Ближний основной / разреженный источник |
| FAR_SYNTHETIC_BEAM | Дальний синтетический источник по лучам |
| SYNTHETIC_MEASURED | B1 в измеренной GOOD-геометрии |
| SYNTHETIC_NOMINAL_BRIDGE | B2 по номинальному правилу за поддержанным концом |
| SYNTHETIC_X1_EXTRAPOLATED | Историческая необязательная ветвь A, выключена |
| NORMAL_MEASURED / SPARSE_MEASURED | Исторические измеренные источники |
| NORMAL_EXTENDED / SPARSE_EXTENDED | Исторические расширенные источники, A выключен |
| GOOD / DEGRADED / INVALID | Приемлемая / ослабленная / недопустимая геометрия |
| CONFIG_RESET / INPUT_ERROR | Сброс конфигурации / ошибка входа |
| TIMESTAMP_ROLLBACK / TIMESTAMP_GAP / FRAME_GAP | Возврат времени / временной разрыв / пропуск кадров |
| NO_FRESH_OUTPUT | Наблюдатель не получил свежий результат |


Коды используются в сообщениях, логах и диагностических структурах ядра. Они сохраняют исходное написание для совместимости потребителей. Смысл публичных полей и правила свежести приведены в [API](API.md). Коды необязательного расширения могут присутствовать в исходниках, но эта ветвь выключена в рабочей конфигурации.
