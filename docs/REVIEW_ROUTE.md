# Маршрут проверки за несколько минут

[Документация](README.md)

## 1. Прочитать результат

Откройте [примеры и метрики](RESULTS.md). Дальности относятся к явно отмеченным предоставленным синтетическим вставкам. Полные показатели ошибок и условия локального нагрузочного теста находятся на той же странице.

## 2. Запустить

Следуйте [инструкции развёртывания](DEPLOYMENT.md). Базовый путь: Docker build, запуск узла, воспроизведение ROS 2 bag, наблюдение состояния и расстояния. Входной bag предоставляется отдельно и монтируется только для чтения.

## 3. Проверить контракт

[API](API.md) описывает поля PointCloud2, семь топиков, единицы расстояния, состояния и контроль свежести.

## 4. Воспроизвести проверки

`python3 validation/check_repository.py` проверяет структуру и целостность.

`python3 -m unittest discover -s tests -v` запускает локальные тесты с NumPy.

Для полной регрессии нужны отдельно передаваемые файлы, перечисленные в [VALIDATION.md](VALIDATION.md). Исходный репозиторий не выдаёт отсутствие большого комплекта за успешный полный прогон.

## Материалы демонстрации

Презентация и видеодемонстрация доступны по отдельным ссылкам формы сдачи. Их файлы не нужны для работы детектора.
