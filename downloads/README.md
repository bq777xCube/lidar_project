# Архивы поставки

Четыре готовых архива доступны в [Release](https://github.com/bq777xCube/lidar_project/releases/tag/submission-2026-09-28). Здесь хранятся их контрольные суммы и сведения о происхождении.

- `SHA256SUMS`, `delivery_receipt.json`: актуальные архивы публикации с уточненными подписями графиков.
- `sealed_delivery_receipt.json`, `SEALED_DELIVERY_STATUS.json`, `sealed_runtime_manifest.json`: неизменные сведения об исходной локальной поставке до публикации.

В исторических документах фраза об отсутствии публикации относится к моменту подготовки этого снимка. Текущий статус размещения: `../PUBLICATION_STATUS.json`. Финальные слайды, данные команды, доступ экспертам и отправка формы по-прежнему требуют действий команды.
