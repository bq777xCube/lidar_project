# Происхождение проверок

Файлы в этой папке фиксируют испытания исходной запечатанной поставки до размещения в GitHub. Их даты, пути, контрольные суммы документации и статус отсутствия публикации сохранены как историческое свидетельство.

Для текущего размещения используйте `../PUBLICATION_STATUS.json`, а для актуальных архивов — `../downloads/delivery_receipt.json` и `../downloads/SHA256SUMS`. Контрольные суммы исходных локальных архивов сохранены отдельно в `../downloads/sealed_delivery_receipt.json`.

При публикации уточнены подписи сравнения и сопроводительные тексты. Код, параметры, Docker-образ и проверочные эталоны не менялись. Новая серия измерений производительности не выполнялась.
