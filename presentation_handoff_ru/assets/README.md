# Иллюстрации основных материалов

E1, E9, E10: настоящие сохранённые облака и увеличенные фрагменты. Малиновым показана существующая поясняющая разметка, золотой звездой выбранная детектором точка. Пустоты между точками не заполнялись. Сохраняйте подписи осей и пропорции изображений.

product_flow: понятная цепочка продукта. algorithm: реализованные связи каналов. integration: запуск в Docker и обмен с ROS 2. Для каждого рисунка есть PNG и SVG. Полный исходник: render_assets.py.

performance.csv содержит только четыре запуска итоговой конфигурации. metrics.csv содержит расстояния и результаты проверки. Точные значения и область измерения: final_metrics.json. Источники точек и разметки, пределы фрагментов и хеши NPZ: provenance.json.

Сравнительных графиков в этой папке нет. Они сохранены отдельно в technical/comparison_assets для технических вопросов. Нельзя приписывать старые сравнительные графики текущему основному рассказу.
