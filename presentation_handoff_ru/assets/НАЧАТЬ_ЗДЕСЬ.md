# Иллюстрации и редактирование

PNG готовы для вставки; SVG сохраняют редактируемые подписи и геометрию графиков. render_assets.py воспроизводит их из chart_data.json и E1/E9/E10_points.npz с NumPy и Matplotlib. Эти библиотеки нужны только автору рисунков, не алгоритму.

provenance.json содержит исходные кэши, их SHA256, source_indices, точную выбранную точку и пределы осей. NPZ содержит ограниченную детерминированную выборку реальных сохраненных точек. Искусственные облака не создавались. Не растягивать графики непропорционально и не убирать подписи области применимости.

Данные графиков совпадают с facts_ru.json. Время взято из подтвержденной серии измерений итогового алгоритма. Статические виды не являются видео работающего алгоритма. Производные данные не объявляются открытыми для неограниченного распространения.
