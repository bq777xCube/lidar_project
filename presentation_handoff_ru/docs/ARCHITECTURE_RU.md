# Архитектура

PointCloud2 поступает в однопоточный узел ROS 2 Humble. Адаптер читает XYZ по описаниям полей, endian, point_step и row_step. Он поддерживает layouts 16/26 и организованные облака; ring, intensity и timestamp не определяют решение ядра.

Ближняя ветвь строит опору по текущему облаку, оценивает рельсы, осевую линию, поддержанный горизонт и габарит. Основное подтверждение и S2 сохраняют прежнее поведение. Дальний канал проверяет согласованность XYZ с замороженной таблицей лучей до нормализации по рельсам. B1 использует измеренную GOOD-геометрию. B2 проверяет область за поддержанным концом через существующее N1-правило. Ветви собираются в прежний публичный результат.

Query-first ограничивает вычисление синтетических свидетельств нужными областями. Глобальный диагностический счетчик не влияет на решение и равен null при debug=false. В полном аудите он вычисляется точно. Исходная геометрия полного входа сохраняется.

Чистые уточнения кэшируются внутри одного кадра. Наблюдения, карты и геометрия между кадрами не кэшируются. C++ ускоряет точный выбор луча с резервной арифметикой NumPy на неоднозначных границах. Флаги компиляции сохраняют порядок численной арифметики.

Вход: best-effort, volatile, depth=1. Выходы: отдельные сообщения depth=1. Новая политика торможения, одометрия и ML отсутствуют.
