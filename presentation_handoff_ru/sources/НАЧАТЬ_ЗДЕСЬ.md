# Источники фактов

JSON и отчёт QUERY-FIRST являются сохранёнными источниками результатов, а не новыми измерениями. Их внутренние пути относятся к исходному проекту. Сопоставление с основными слайдами и определения находятся в ../Техническое_приложение.md.

object_annotations.json содержит только существующую разметку трёх иллюстраций, с хешем исходного отчёта. scenarios.json и scenarios.md сохраняют названия предоставленных сценариев. Старые проверки не заменены новыми метриками.
