# Лицензии и происхождение

Исходные поля package.xml/setup.py содержат Proprietary. Новая лицензия проекта не назначалась. Исторические maintainer/example.invalid являются техническими метаданными и не контактами команды. Команда должна определить права и фактические контакты перед публикацией.

Runtime использует ROS 2 Humble (rclpy, сообщения, launch, ament), NumPy, Python, setuptools, Fast DDS и базовые пакеты Ubuntu. Их upstream-лицензии и юридические уведомления сохраняются в исходном образе и установленных пакетах; этот документ их не заменяет. Список реально установленных Debian-пакетов находится в образе `/opt/detector/build-packages.txt`; уведомления `/usr/share/doc/*/copyright` доступны в контейнере. Зависимости не перелицензируются.

Собственный C++ селектор собирается прежними флагами; сторонний код для этой локализации не импортировался. Официальный шаблон сохраняет оформление и авторские элементы организаторов. Предоставленные bag не включены ни в репозиторий, ни в архивы. Производные проверочные выборки передаются отдельно для воспроизведения с учетом исходных условий доступа, не объявляются общедоступными данными.
