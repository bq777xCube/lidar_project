# Автономная проверка

Требуются Docker, Bash, Python 3 на хосте (только стандартная библиотека) и загруженный RU-образ. На M4 amd64 выполняется в эмуляции. Алгоритм не обращается к сети.

```bash
gzip -dc lidar-near-v5-query-first-ru-amd64.tar.gz | docker load
tar -xzf lct26_task5_validation_ru.tar.gz
bash validation/validate_ru.sh "$PWD/ru_validation_run"
```

Укажите новый каталог: сценарий отказывается перезаписывать предыдущий результат. Он проверяет SHA256 четырех неизменных архивов v4/v5, отвергает небезопасные пути и коллизии, распаковывает их и монтирует только распакованный комплект. Исходный каталог разработки не используется.

Проверяются исходники/установленный пакет по новому RU-манифесту и семантическая эквивалентность старому v5. Старые ожидаемые значения и хеши не переписаны. Отдельно выполняются точные T0/T3 сравнения на 262 записях для каждого режима, исходные 262 fallback records, 40 baseline tests, 1730 far checks, 12 focused tests, причинный DDS smoke E10/S2 с семью выходами, layouts16/26, rollback/reset и malformed. Focused tests проверяют точные границы, состав B1/B2 и audit/оперативный счетчик.

Сравнение исключает только прежние поля измеренного времени. Историческая межплатформенная погрешность 1e-5 не расширена. Результаты JSON находятся в ru_validation_run/results. Команда завершается ненулевым кодом при любой ошибке. Runtime работает и без распаковки validation.

Исторические неизменные сценарии и эталоны могут содержать английский текст и строки происхождения. Они являются проверочными данными, не русской документацией. Производные данные не объявляются открытыми для неограниченного распространения.
