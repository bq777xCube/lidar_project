# Повторная сборка оформления

Нужны Python 3, NumPy, Matplotlib и ReportLab. Для рендера страниц нужен Poppler. Шрифты DejaVu включены в fonts/ вместе с лицензией. Генераторы используют только данные этого пакета, не читают bag, не запускают детектор и не обращаются к сети.

Из корня пакета:

```bash
MPLCONFIGDIR=/tmp/lidar-presentation-mpl OPENBLAS_NUM_THREADS=1 python3 assets/render_assets.py
python3 overview_pdf.py
mkdir -p preview
pdftoppm -scale-to 1600 -png Обзор_решения.pdf preview/page
```

При повторной сборке проверьте все пять страниц: кириллицу, переносы, легенду, оси, таблицы и отсутствие наложений. Не заменяйте реальные точки генеративными изображениями. Цветная разметка берётся из существующих reference_indices, выбранная точка из исходного NPZ. Внутренние источники сохранены отдельно.

Файлы technical/comparison_assets/ относятся к старому техническому приложению. Их генератор не нужен для основного обзора. Переиспользуйте только актуальные PNG/SVG из assets/.
