# Проверка решения

Порядок проверки: **[инструкция](../docs/VALIDATION.md)**.

- `check_repository.py`: локальная проверка структуры, хешей, ссылок и синтаксиса без ROS.
- `source_integrity.json`: контрольные суммы перенесённого исполняемого кода.
- `receipts/`: исторические подтверждения установленного пакета и его среды.
- `validate_ru.sh`, `tools/`: процедура полного прогона с отдельно передаваемым регрессионным комплектом.

Локальные программные тесты находятся в `../tests/`. Большие эталоны не включены. Полный `validate_ru.sh` запускают из распакованного полного проверочного комплекта, где доступны `archives/` и `solution/`.
